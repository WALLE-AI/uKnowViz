连续化 Softmax Attention

把“对有限个向量做加权平均”变成“对一条连续曲线求积分”，再重新离散化——会得到什么？

解读自 苏剑林（科学空间）《连续化 Softmax Attention》

⓪先用大白话理解：这篇文章在讲什么？

Attention（注意力）是 ChatGPT 这类大模型的核心零件。它解决的问题是：读到某个词时，应该“回头看”前面哪些词、各看多少？

🔍
Query（查询）
当前这个词提出的“问题”。
比如读到“它”，问的是：“它”指谁？
🏷️
Key（标签）
前面每个词身上贴的“标签”。
问题和标签越匹配，打分 $a_i$ 越高。
📦
Value（内容）
每个词真正携带的信息。
最后按分数比例把内容“混合”起来。

Softmax 就是把分数变成“注意力份额”的规则：先取 $e^{a_i}$（让高分更突出），再除以总和，使所有份额加起来正好等于 100%。这好比按得分把一块蛋糕分给几个人。

普通的注意力只关心一个个独立的词，就像只在 1 号、2 号、3 号……这些“站点”上收集信息。

这篇文章换了个想法：如果把相邻站点之间用直线连起来，假设信息在两个词之间是“渐变”的，那么注意力就不再是一根根柱子，而是一条连绵的“山脉”。这时就不用“把柱子加起来”，而是去算山脉下面的面积（也就是积分）。

这就叫“连续化”。数学上把积分算出来、再还原成能在电脑上计算的形式，叫“重新离散化”。

🎯 一句话结论：连续化之后，结果仍然是普通的 Softmax 注意力，只是每个词的分数会参考左右邻居的分数，自动做一点“平滑”：太突出的被削低一点，被冷落的被抬高一点。这相当于给注意力加了一个“模糊滤镜”，业内叫 Short Conv（短卷积）。
📉 实验结果：训练初期确实学得更快，但最后和普通版本打平，而且计算速度只有原来的约 1/4。所以它目前更像一个“数学上很漂亮”的发现，而不是实用的改进。

下面的章节带你一步步看这个结论是怎么来的。每一节都有一个 🧒“通俗地说”框，看不懂公式的话，只看这些框和动画也能明白大意。

①问题：把求和换成积分

标准 Softmax Attention 只在整数位置 $i=1,\dots,t$ 上取值：

$$\boldsymbol{o}_t = \frac{\sum_{i=1}^t e^{\boldsymbol{q}_t\cdot\boldsymbol{k}_i} \boldsymbol{v}_i}{\sum_{i=1}^t e^{\boldsymbol{q}_t\cdot\boldsymbol{k}_i}}$$

连续化版本把它改成在 $[0,t]$ 上的积分：

$$\boldsymbol{o}_t = \frac{\int_0^t e^{\boldsymbol{q}_t\cdot\boldsymbol{k}_s} \boldsymbol{v}_s\, ds}{\int_0^t e^{\boldsymbol{q}_t\cdot\boldsymbol{k}_s}\, ds}$$

非整数点的 $\boldsymbol{k}_s,\boldsymbol{v}_s$ 用线性插值定义，对 $s\in[i-1,i]$：

$$\boldsymbol{k}_s = (i - s)\boldsymbol{k}_{i-1} + (s - i + 1) \boldsymbol{k}_i$$

$\boldsymbol{v}_s$ 同理。为了让 $[0,1]$ 这一段有定义，需要额外引入 $\boldsymbol{k}_0,\boldsymbol{v}_0$（类似一个 Sink token）。

关键观察：$\boldsymbol{k}_s$ 对 $s$ 线性 ⇒ 分数 $a_s=\boldsymbol{q}_t\cdot\boldsymbol{k}_s$ 也对 $s$ 线性 ⇒ 每一段上 $e^{a_s}$ 都是一段指数曲线，可以精确积分。

标准：只在整数点有权重 $e^{a_i}$ 连续化：$e^{a_s}$ 曲线下的面积（$a_s$ 分段线性） $v_s$（以标量演示，右侧坐标）
  • 绿色柱子：普通注意力。每个位置一根柱子，柱子越高，越受关注。
  • 点 ▶ 播放：柱子逐渐消失，换成一条紫色山脉。山脉在每个整数位置正好经过柱顶，柱子之间则平滑过渡。
  • 黄色折线是每个位置携带的“内容”$v$（这里用一个数代替一个向量），它也被连成了折线。
  • 最后的输出 $o_t$ = “内容 × 关注度”的总面积 ÷ 山脉总面积，相当于按面积加权的平均值。
想象你坐火车，只在 1、2、3…号站停靠拍照，这是普通注意力。连续化则是全程开着摄像机，站与站之间的风景也被记录下来（用直线“脑补”）。最后统计“看到了什么”时，不再只数照片，而是看整段录像。 下方读数中“数值积分”和“闭式解”几乎完全一样，说明后文推出的公式是对的。

②单段积分：一段面积如何“分给”两个端点

记 $a_{t,i} = \boldsymbol{q}_t\cdot\boldsymbol{k}_i$，$\delta_{t,i}=a_{t,i}-a_{t,i-1}$。在第 $i$ 段上，把 $s$ 平移到 $[0,1]$：

$$e^{a_s}\boldsymbol{v}_s = \underbrace{e^{a_{i-1}+s\delta}(1-s)}_{\color{#f59f4c}\text{给 }\boldsymbol{v}_{i-1}}\,\boldsymbol{v}_{i-1} + \underbrace{e^{a_{i-1}+s\delta}\, s}_{\color{#4dabf7}\text{给 }\boldsymbol{v}_{i}}\,\boldsymbol{v}_{i}$$

也就是说，曲线 $e^{a_s}$ 下的面积被权重 $(1-s)$ 与 $s$ 切成两块（下图橙色与蓝色），分别积分得到：

$$\int_{i-1}^i e^{a_s} \boldsymbol{v}_s ds = {\color{#f59f4c}e^{a_{i-1}}\varphi_2(\delta)}\,\boldsymbol{v}_{i-1} + {\color{#4dabf7}e^{a_{i}}\varphi_2(-\delta)}\,\boldsymbol{v}_{i},\qquad \int_{i-1}^i e^{a_s} ds = e^{a_{i-1}}\varphi_1(\delta)$$
💡 当 $\delta=0$（相邻两个分数相同）时，两块面积各占一半 —— 这正是梯形求积公式；$\delta\ne 0$ 时，分数更高的那一端会“抢走”更多面积。
只看相邻两个位置之间的这一小段山坡。这块面积最后要“还”给两个端点，问题是各还多少？
  • 规则很直观：离谁近就归谁。靠近左端的部分大多归左边（橙色），靠近右端的部分大多归右边（蓝色）。
  • 如果两端一样高（点“令 δ=0”），就正好对半分。这和小学学的梯形面积公式“(上底+下底)×高÷2”是一回事。
  • 如果一端更高，山坡在那一侧更“胖”，那一端就分得更多。拖动滑块试试，右边的柱子会显示分配比例。
就像两个村子之间有一片农田，按“离哪个村更近”来划分归属，地势更高（更肥沃）的那一侧收获更多。

③两个辅助函数 $\varphi_1,\varphi_2$

$$\varphi_1(x) \triangleq \int_0^1 e^{s x} ds = \frac{e^x - 1}{x}$$ $$\varphi_2(x) \triangleq \int_0^1 e^{s x} (1-s) ds = \frac{e^x - 1 - x}{x^2}$$

$x=0$ 处取极限：$\varphi_1(0)=1,\ \varphi_2(0)=\tfrac12$。由积分定义可知二者恒正，后面取对数不会出问题。

关键恒等式（把 $\boldsymbol{v}_i$ 的系数改写成以 $e^{a_i}$ 为基准）：

$$\varphi_1(x) - \varphi_2(x) = e^x \varphi_2(-x)$$

含义：$\int_0^1 e^{sx}s\,ds$（蓝色那块）从右端点看过去，就是把 $x$ 反号后的 $\varphi_2$，再乘以 $e^x$。

$\varphi_1(x)$ $\varphi_2(x)$ $e^x\varphi_2(-x)$ $\varphi_1-\varphi_2$（虚线，与蓝线重合）
$\varphi_1$ 和 $\varphi_2$ 不神秘，它们只是两个“记账工具”：
  • $\varphi_1$ 算的是上一节那一整段山坡的总面积（以左端高度为单位）。
  • $\varphi_2$ 算的是其中分给左端点的那一块（橙色）。
  • 恒等式 $\varphi_1-\varphi_2=e^x\varphi_2(-x)$ 的意思是：总面积减去橙色，就是蓝色；而蓝色从右端点看过去，和橙色是同一种形状，只是方向反过来。所以一个 $\varphi_2$ 就能同时描述左右两份。
不用记公式，只需记住两点：它们永远是正数；两端一样高时，$\varphi_1=1$（整块），$\varphi_2=\tfrac12$（一半）。

④组装：每个端点收集左右两段送来的面积

把所有段的结果加起来并按 $\boldsymbol{v}_i$ 合并同类项。点 $i$ 会从左边那段收到蓝色份额 $e^{a_i}\varphi_2(-\delta_i)$，从右边那段收到橙色份额 $e^{a_i}\varphi_2(\delta_{i+1})$：

$$\text{分子}= \sum_{i=0}^t e^{a_{t,i} + b_{t,i}} \boldsymbol{v}_i,\qquad e^{b_{t,i}} = \left\{\begin{aligned} &\varphi_2(a_{t,1} - a_{t,0}) && i = 0 \\ &\varphi_2(a_{t,i-1} - a_{t,i}) + \varphi_2(a_{t,i+1} - a_{t,i}) && 1\leq i\leq t-1 \\ &\varphi_2(a_{t,t-1} - a_{t,t}) && i = t \end{aligned}\right.$$

分母就是把所有 $\boldsymbol{v}_i$ 换成 $1$，于是最终仍然是一个 Softmax：

$$\boxed{\ \boldsymbol{o}_t = \frac{\sum_{i=0}^t e^{a_{t,i} + b_{t,i}} \boldsymbol{v}_i}{\sum_{i=0}^t e^{a_{t,i} + b_{t,i}}}\ }$$
橙：段的左份额 → 左端点 蓝：段的右份额 → 右端点 虚线框：标准 Softmax 的权重 $e^{a_i}$
  • 上半部分：整条山脉被切成若干段，每段都分成橙、蓝两块。
  • 点 ▶ 播放：每段的橙色块飞向左边的端点，蓝色块飞向右边的端点，在下半部分堆成柱子。
  • 绿色虚线框是普通注意力给这个位置的权重，可以和堆出来的柱子比一比。
每个位置都从左右两块农田各收一份粮食，加起来就是它最终的“关注度”。
  • 和普通注意力相比，相当于给每个位置的分数乘了一个修正系数 $e^{b_i}$。
  • 这个系数由“我和邻居谁高谁低”决定：邻居比我高，我能多分一点；邻居比我低，我会少一点。
  • 第一个和最后一个位置只有一侧有邻居，只能收到一份，所以大约只有一半（$b\approx\log\frac12$）。
最妙的是，最后的公式还是 Softmax 的样子，只是分数从 $a_i$ 变成了 $a_i+b_i$。这意味着它很容易“塞进”现有的模型里。

⑥$b_{t,i}$ 本质上是一个 Short Conv

对内部点做泰勒展开（$\varphi_2(x)=\tfrac12+\tfrac{x}{6}+\tfrac{x^2}{24}+\cdots$）：

$$b_{t,i} = \log \big(\varphi_2(a_{t,i-1} - a_{t,i}) + \varphi_2(a_{t,i+1} - a_{t,i})\big) = \frac{a_{t,i-1} + a_{t,i+1} - 2a_{t,i}}{6} + \cdots$$

$a_{t,i-1} + a_{t,i+1} - 2a_{t,i}$ 正是二阶差分，即沿 $i$ 方向用核 $[\tfrac16,-\tfrac13,\tfrac16]$ 做的卷积。于是

$$a_{t,i}+b_{t,i}\approx \tfrac16 a_{t,i-1}+\tfrac23 a_{t,i}+\tfrac16 a_{t,i+1}$$

——连续化 ≈ 给 Attention 分数矩阵沿 key 方向做了一次平滑的 Short Conv。而两个端点 $i=0,t$ 只有一侧邻居，大约只拿到 $\log\frac12$，对应梯形公式端点的半权重。

这就像手机修图里的“模糊/柔化滤镜”：每个像素都和左右邻居按 $\tfrac16:\tfrac23:\tfrac16$ 的比例取平均，结果是尖的变钝，凹的变满。
  • 拖动上面三个滑块，把中间的 $a_i$ 调得比两边高：紫色柱（修正后）会比原来矮。
  • 把中间调得比两边低：修正后反而会变高。
“Short Conv（短卷积）”正是这种“只看左右几个邻居”的小滤镜，它是近几年很多新模型（如 Mamba 等线性注意力类模型）里常用的小技巧。这篇文章的有趣之处在于：没人刻意设计它，只是“把求和改成积分”，这个滤镜就自己冒出来了。

⑦作者的简单实验

效率
≈ 1/4

$b_{t,i}$ 依赖相邻分数，无法直接复用 Flash Attention。理论 FLOPs 基本一致，但作者让 K3 写的 Kernel 中细碎运算太多，速度只有标准 Softmax Attention 的约 1/4。

位置编码
仍需 RoPE

连续化引入了局域先验，但不能替代位置编码：全 Full Attention 架构下，不加 RoPE 的连续化版本明显差于“标准 + RoPE”；加上 RoPE 后差距被追回。

训练动态
先优后平

都加 RoPE 时，连续化前期明显更好，但差距逐渐缩窄，训练结束时两者基本重合。中途从标准版切换到连续化，起跳 Loss 不高，最终收敛到与标准版基本一致。

上图是根据文中文字描述绘制的定性示意图，并非原文数据。作者推测：自然语言并非真正的时间序列，连续化带不来实质好处；在真正的时间序列任务上或许才能测出优势。

一句话：理论漂亮，实战打平。
  • 为什么慢？ 现在的大模型靠一个叫 Flash Attention 的“加速引擎”跑得飞快，但它只认标准公式。新公式要额外看邻居，引擎用不上，只能手写，于是慢了约 4 倍。
  • 为什么还要 RoPE（位置编码）？ 连续化只让模型知道“谁和谁相邻”，却不知道“隔了多远”“谁在前谁在后”。这些仍然要靠位置编码提供。
  • 为什么最终没优势？ 连续化默认两个词之间存在“渐变的中间状态”。温度、股价这类数据确实如此，但语言不是：在“苹果”和“跑步”之间，并不存在一个“一半苹果一半跑步”的词。前期它像一副“辅助轮”帮模型起步，等模型学会了，辅助轮就没用了。

⑧小结

步骤做了什么得到什么
连续化$\sum_i \to \int_0^t ds$；$\boldsymbol{k},\boldsymbol{v}$ 线性插值；补 $\boldsymbol{k}_0,\boldsymbol{v}_0$每段 $e^{a_s}$ 为指数曲线，可精确积分
分段积分按 $(1-s)$、$s$ 把每段面积切给左右端点$\varphi_1,\varphi_2$ 与恒等式 $\varphi_1-\varphi_2=e^x\varphi_2(-x)$
重新离散化按 $\boldsymbol{v}_i$ 合并同类项仍是 Softmax，分数变为 $a_{t,i}+b_{t,i}$
解读对 $b_{t,i}$ 泰勒展开≈ 二阶差分/6 ⇒ 注意力矩阵上的 Short Conv；$\boldsymbol{k}_0,\boldsymbol{v}_0$ ≈ Sink token
实验语言模型预训练前期更快、最终持平；需 RoPE；速度约 1/4
“连续化 → 离散化”是一条屡试不爽的探索路径（SSM、EFLA 皆如此）。对 Softmax Attention 而言，它重新推出了一个漂亮的结论：连续化 Softmax Attention ≈ 给 Attention 矩阵加 Short Conv。在自然语言上虽未见收益，但仍是一个值得赏析的结果。
用三句话讲给朋友听：
  1. 大模型读文字时，会给前面每个词打分，再按分数“分配注意力”。
  2. 如果假设词与词之间是平滑过渡的，用“算面积”代替“数柱子”，推导出来的新规则等于：每个词的分数先和左右邻居平均一下，再分配注意力。
  3. 这个想法让模型起步更快，但最终效果和原来一样，还更慢。它的价值在于揭示了“连续化”和“短卷积”这两个看似无关的东西其实是相通的。

📖术语表

Attention 注意力
模型在处理当前词时，决定“回头看”哪些词、各看多少的机制。
Query / Key / Value
问题 / 标签 / 内容。用问题匹配标签得到分数，再按分数混合内容。
Softmax
把一组任意分数变成加起来为 100% 的份额：先取指数，再除以总和。高分会被放大。
注意力矩阵
把“每个词对每个前面的词的关注度”排成的表格，第 5 节的热力图就是它。
Causal 因果
只能看前面、不能看后面的词（生成文字时还不知道未来）。
线性插值
在两个已知点之间连一条直线，用来“猜”中间的值。
积分
求曲线下方的面积，可以看成“连续版本的求和”。
连续化 / 离散化
把一个个点变成连续的线 / 再把连续的结果写回按点计算的公式。
泰勒展开
用简单的多项式近似复杂的函数，只保留最主要的项，便于看清本质。
二阶差分
$a_{i-1}+a_{i+1}-2a_i$：衡量一个点比左右邻居“凸出”或“凹陷”了多少。
Short Conv 短卷积
只用相邻几个位置做加权平均的小滤镜，类似图片的模糊滤镜。
Sink token
在序列开头额外放的一个“空位”，让注意力在没什么可看时有地方“停靠”。这里的 $\boldsymbol{k}_0,\boldsymbol{v}_0$ 起类似作用。
RoPE 位置编码
告诉模型每个词在第几个位置、彼此相距多远的方法（旋转位置编码）。
Flash Attention
一种高度优化的注意力计算程序，速度快、省显存，但只支持标准公式。
SSM / EFLA
同样采用“先连续化、再离散化”思路设计出来的其他序列模型。
