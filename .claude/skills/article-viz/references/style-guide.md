# UI 样式与交互规范

所有页面共享 `viz-core.css`，读者在多篇文章间切换时，**同一种颜色、同一种控件永远代表同一件事**，这样每一篇都更好读。所以：不要为单篇文章另起配色，不要重写已有的组件样式；页面专属样式只用于布局微调。

## 1. 语义配色

| 变量 | 颜色 | 永远代表 | 图例类名 |
|---|---|---|---|
| `--new` | 紫 #b197fc | 文章提出的**新方法 / 主角** | `sw new` |
| `--base` | 绿 #69db7c | **基线 / 标准做法**；读数中的 ✓ | `sw base` |
| `--pa` | 橙 #f59f4c | 一分为二时的 **A 部分**（左 / 第一项 / 分给前者的） | `sw pa` |
| `--pb` | 蓝 #4dabf7 | 一分为二时的 **B 部分**（右 / 第二项 / 分给后者的） | `sw pb` |
| `--approx` | 黄 #ffd43b | **近似值 / 辅助量 / 输入数据** | `sw approx` |
| `--warn` | 红 #ff8787 | **负面结果 / 误差 / 警告** / 示意水印 | `sw warn` |
| `--text` / `--muted` / `--dim` | 白 / 灰 / 暗灰 | 主体 / 次要标注 / 不重要的参考物 | |

- 新方法和基线同时出现时，永远是紫 vs 绿。
- 文字中提到颜色时用 `<span style="color:var(--pa)">橙</span>` 呼应画面。
- 公式里也可以着色：`{\color{#f59f4c} ...}`，用来把公式项和画面区域对应起来（范例 ②）。
- 不要只靠颜色区分：每张图都要有图例或直接的文字标注。

## 2. 页面结构（固定顺序）

```
header.hero    标题 + 一句钩子（提出问题，不剧透结论）+ 出处
nav.toc        章节锚点（sticky）
⓪ 大白话版     不看公式也能读懂全文：背景 → 核心比喻 → 一句话结论（.key）
①…⑨ 正文章节  按推导链展开，每节一个核心想法
∑ 小结         表格（步骤/做了什么/得到什么）+ .key 洞见 + “三句话讲给朋友听”
📖 术语表      dl.gloss
footer         原文链接 + 返回目录
```
章节数通常 4–9 个。原文较短时宁可少而精，不要为了凑数拆碎。

## 3. 章节解剖（每节都按这个顺序）

1. `h2`：`<span class="num">①</span>` + 一句话标题（说清这一节的结论，而不是只写“推导”）。
2. **公式层**：`.card` 中给出原文公式（LaTeX 逐字保留）和必要的文字。两张卡并排用 `.grid2`。
3. **动画层**：`canvas` → `.controls` → `.legend` → `.readout`。
4. **解释层**：`.plain.how`（👀 怎么看这张图：颜色含义 + 先点什么、拖什么、观察什么）→ `.plain`（🧒 通俗地说）。
5. 可选 `.key`：本节最重要的一句洞见。

## 4. 画布与控件

- 画布高度用内联样式：普通图 280–340px，上下分栏 420–480px，三联热力图 260–280px。
- **首帧必须有信息量**：不点任何按钮时，画面也要能看出要点（例如形变动画首帧显示原始柱子，而不是空白）。
- 每个动画都必须**可拖动**：播放按钮 + 进度滑块（`VIZ.player`），读者能停在任意一帧。
- 每个参数化的图至少有一个能“玩”的滑块，并配一个让现象变极端或变平凡的按钮（如“令 δ=0”）。
- 随机数据配“🎲 随机”按钮；默认数据要挑一个能体现现象的例子（必要时用 `VIZ.rng(seed)` 固定）。
- 按钮文字：主操作 `button.primary`，以 ▶ 开头；其他用普通 `button`，可带 emoji。
- 滑块标签可以用 LaTeX（`$\delta$`），数值显示用 `<span class="val" data-for="id">`。
- 动画时长：单个形变 2–3 秒；逐项过程每项 1–1.5 秒；不要超过 8 秒。

## 5. 读数区（.readout）

- 等宽字体、列对齐（`fmt` 自动补空格）。
- 优先展示**核对**：闭式解 vs 数值计算、恒等式两侧、近似 vs 精确，后面跟 `<span class="ok">✓</span>`。读者看到 ✓ 会相信推导，也让你自己发现公式写错。
- 关键数值用 `<b>` 高亮（紫色）。
- 画布内文字用 ASCII/Unicode（`e^(a_s)`、`φ₂`、`a_{i−1}`），因为 canvas 不渲染 LaTeX。
- 画布边缘的标注**朝内对齐**：左端点的标签 `align:'left'` 并向右偏移，右端点的标签 `align:'right'` 并向左偏移，否则会被裁掉或压到坐标轴上。
- 读数行尽量短（≤ 70 个半角字符）：中文全角字符与等宽字体混排时对不齐，长行在窄卡片（`.grid2`）里还会折行。

## 6. 文字排版

- 中文正文，术语首次出现时附英文（如“短卷积（Short Conv）”）。
- 行内公式 `$...$`，独立公式 `$$...$$`；`.readout` 内不渲染公式。
- 加粗只给真正的关键词，一段不超过 2–3 处。
- 正文语气：讲解者对聪明的外行说话；不用“显然”“易得”。

## 7. 首页索引

scaffold.py 生成页面时写入 `<meta name="viz:*">`；`build_index.py` 根据它重建根目录的 `index.html`。修改标题或一句话总结后，重新运行 `build_index.py`。
